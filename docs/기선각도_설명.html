가로선은 왜 깊이를 못 주는가

굴림 0°에서 가로선의 깊이가 안 나오는 것은 알고리즘이 부족해서가 아니라 방정식에서 깊이 항이 사라지기 때문입니다. 같은 식이, 격자를 굴리는 것 말고 카메라를 대각으로 다는 두 번째 해법도 알려 줍니다.

근거 eq7_laser_plane.py 검증 72개 배치 조합 그림 실제 코드 식으로 작도

깊이가 변하면 화소는 오직 기선 방향으로만 움직인다. 선이 그 방향과 나란하면, 선은 자기 위를 미끄러질 뿐이다.

그래서 깊이를 잴 수 있는지는 “가로선이냐 세로선이냐”가 아니라 선과 기선이 이루는 각 하나로 정해집니다.

1

식은 세 줄이면 끝납니다

조사기가 원점이고 카메라는 기선 b만큼 떨어져 있습니다. 레이저 평면은 원점을 지나므로 n·P = 0이고, 화소 하나의 시선은 P = b + Z·(û, v̂, 1)입니다. 대입하면:

레이저 평면 n·P = 0 카메라 시선 P = b + Z·(û, v̂, 1) ────────────────────────────────────────── n·b + Z·(nxû + nyv̂ + nz) = 0 깊이 Z = − (n·b) / (nxû + nyv̂ + nz)

마지막 줄이 이 문서의 전부입니다. 깊이 Z는 오직 (n·b)를 통해서만 식에 들어옵니다. n·b = 0이면 분자가 0이 되어 방정식이 Z를 아예 담고 있지 않습니다 — 어떤 검출 알고리즘도 없는 정보를 만들어 낼 수는 없습니다.

굴림 0°의 가로선이 정확히 그 경우입니다. 평면 법선이 n = (0, −cos β, sin β)이고 기선이 b = (b, 0, 0)이라 n·b = 0.00000 — 레이저 평면이 카메라 광학중심을 그대로 지나갑니다.

2

화면에서 보면 이렇게 됩니다

같은 레이저 선이 배경 1.50 m에 맺혔을 때와 앞의 부재 1.20 m에 맺혔을 때를 겹쳐 그린 것입니다. 세 그림 모두 위 식으로 직접 작도했습니다.

3

정밀도를 정하는 것은 각 하나뿐입니다

선이 얼마나 움직이는지는 이동량 중 선에 수직인 성분만입니다. 나란한 성분은 선을 자기 위로 미끄러뜨릴 뿐이니까요. 그래서 깊이 잡음 배수는 각 하나로 정리됩니다. 굴림·발사각·기선 각도를 바꿔 가며 72개 조합에서 정확식과 일치하는 것을 확인했습니다.

정확식 g = |b|·√(nx² + ny²) / |n·b| 같은 값 g = 1 / |sin θ| θ = 화면에서 레이저 선과 기선이 이루는 각

σ_Z = g · Z²/(f·b) · σ_u  —  예제 사양에서 1 px = 15.9 mm @ 1.5 m

4

각을 만드는 방법은 두 가지입니다

식이 요구하는 것은 “격자가 화면에서 기울 것”이 아니라 선과 기선이 나란하지 않을 것입니다. 그러니 격자를 돌리든 기선을 돌리든 똑같습니다. 다만 보이는 것이 다릅니다.

DOE를 굴린다

  • 격자 무늬가 화면에서 20° 기울어 보임
  • 세로선 g 1.06 / 가로선 g 2.92 — 한쪽이 나쁨
  • 선이 부재를 가로질러 지나 도막으로만 걸림 → 축 방향이 덜 정밀
  • 장비 내부 조립으로 해결
실측 축 수직도 오차 0.50°

카메라를 대각으로 단다

  • 격자는 화면에서 반듯한 채로 유지
  • 세로·가로 둘 다 g 1.41 — 균형이 맞음
  • 세로선이 연직 부재의 전 길이를 훑음
  • 카메라 브래킷 위치만 바꾸면 됨
