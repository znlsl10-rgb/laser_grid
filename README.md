# 레이저 그리드 기반 현장 품질검측 — 영역별 검측 파이프라인

현장 사진 한 장에 벽·바닥·동바리·철근이 함께 들어와도, 영역을 나눠 각 부재에
맞는 검측식(수직도·수평도·평활도)을 적용한다.

기존 파이프라인은 `STATIONS` 딕셔너리에 "이 스테이션은 수직도"라고 적어두고
화면 전체를 단일 평면으로 적합했다. 즉 **무엇을 보고 있는지가 인지가 아니라
설정값**이었다. 이 저장소의 변경은 그 결정을 세그멘테이션 결과에서 가져온다.

---

## 파이프라인

```
1 shot = (rgb_off, rgb_on, IMU ĝ, calib)
 ├─[A ] 선검출        rgb_on  → {lid: [(u,v)…]}      A_선검출.py
 ├─[C ] 영역분할      rgb_off → label_map            C_영역분할.py
 ├─[eq1] 삼각측량             → (X,Y,Z) 조사기 좌표계  eq1_triangulation.py
 ├─[eq5] 영역 할당            → 침식·불연속 제거, 융합  eq5_region_assign.py
 └─ 영역별 검측                                       pipeline_region.py
     벽·거푸집·조적  → eq2 평면(TLS) → eq3 수직도(중력) + eq4·eq6 평활도
     바닥·슬래브     → eq2 평면(TLS) → eq3 수평도(중력) + eq4·eq6 평활도
     동바리·기둥·철근 → eq2 축(RANSAC) → eq3 축 수직도(중력)  [평활도 N/A]
     전 영역        → eq5 불확실도 → 합격 / 기준초과 / 측정불가 / 판정보류
```

**세그멘테이션은 레이저 OFF 프레임을 쓴다.** ON 프레임은 초록 격자선이 화면을
덮어 모델이 선을 물체 경계로 오인한다. 하드웨어는 차영상 모드를 위해 이미
ON/OFF 두 프레임을 수십 µs 간격으로 찍으므로, 마스크가 픽셀 단위로 그대로
정합된다. 추가 비용 없이 문제가 사라진다.

## 실행


돌린다.

## 설계상 중요한 결정

### 1. 중력 기준으로 통합했다
기존 식은 벽에 `arcsin(|n_y|)`, 바닥에 `arccos(|n_z|)` 로 **서로 다른 축**을
읽었다. 이는 "장비를 각 면에 정면으로 겨눈다"는 전제에서만 성립하는데, 한 장에
벽(정면)과 바닥(경사)이 함께 들어오면 두 면에 동시에 정면일 수 없다.

```
벽(면)      θ = arcsin(|n̂ · ĝ|)      완전수직 → 0°
바닥(면)    θ = arccos(|n̂ · ĝ|)      완전수평 → 0°
동바리(축)  θ = arccos(|d̂ · ĝ|)      완전수직 → 0°
```

기존 식은 `ĝ=(0,1,0)` / `(0,0,1)` 인 특수해이므로 검증값이 그대로 재현된다.
부수적으로 v1 자체검증이 수평도에서 88°(참값 2°)로 실패하던 문제가 사라졌다.

### 2. 평면적합을 방향 무관으로 바꿨다
`Z = aX + bY + c` 회귀는 광축과 나란한 면(비스듬히 들어온 바닥)을 표현할 수
없다. 경사 바닥 실측 법선오차 **8.45° → 0.0013°**, 정면 벽은 양쪽 동일.

### 3. 동바리·철근은 평면이 아니다
1D 선형 부재이므로 축을 적합한다. 얇은 부재는 마스크 실루엣에서 반드시
오염되므로 **RANSAC 축 적합**을 쓴다 (오염 16%에서도 정답 복구).

### 4. 평활도는 KCS 직선자로 판정한다
전역 평면 잔차와 자 처짐량은 다른 값이다.

| | eq4 전역잔차 | 3m 자 처짐 |
|---|---|---|
| 전역 휨 12mm | 7.90mm | 0.54mm |
| 국소 융기 6mm | 0.72mm | 4.67mm |

eq4 는 요철의 **위치**를 찾고, eq6 이 **판정**한다.

### 5. 판정하지 않는 상태를 따로 둔다
- **측정불가**: σ_n = σ_Z/cos(입사각) 이 목표(±2mm)를 넘어 값 자체를 못 믿음
- **판정보류(분해능)**: 값은 허용 이내이나 요철 폭이 분해능보다 좁아 하한값임

과소평가는 기준초과를 합격으로 내보내는 방향이라, 이 구분이 없으면 위험하다.
(실측: GT 8mm 융기 → 자 처짐 5.6mm → 허용 7mm 대비 거짓 "합격")

## 검증 결과

### 합성 씬 (벽 + 바닥 + 동바리, 장비 22° 하향)

| 부재 | 검측 | 정답 | gt 백엔드 | geom 백엔드 |
|---|---|---|---|---|
| 벽 | 수직도 | 0.50° | 오차 0.0016° | 0.0012° |
| 바닥 | 수평도 | 0.30° | 오차 0.0161° | 0.0049° |
| 동바리 | 축 수직도 | 1.20° | 오차 0.0499° | 0.0443° |
| 벽 | 평활도 | 융기 6mm | 자 처짐 5.21mm (상한 6.54mm) | — |

### 세그멘테이션 훼손 강건성 (허용 ±0.5°)

| 조건 | 최악 오차 |
|---|---|
| 정답 마스크 (기준선) | 0.0499° |
| 마스크 ±1~16px 어긋남 | 0.0675° |
| 라벨 오분류 (100% 포함, 9종) | 0.0499° |
| 부재 누락 | 놓친 부재만 빠지고 나머지 영향 없음 |

**세그멘테이션은 "무엇을 재야 하는지"를 정하고, "얼마인지"는 기하가 결정한다.**
네 겹의 방어가 작동한다 — 평면·축 적합의 다수점 평균, 의미×기하 융합,
병합 영역 재분할, 얇은 부재 robust 축 적합.

다만 다음 둘은 세그멘테이션 품질이 그대로 결과가 된다.
- **부재 종류 구분** — 동바리/기둥/철근, 벽/거푸집/조적은 기하가 구분하지
  못한다. 틀리면 각도는 맞아도 KCS 허용치를 잘못 적용한다.
- **평활도** — 영역 경계와 점 밀도에 직접 좌우된다.

## 알려진 한계

- **평활도 과소보고 (15~40%)**: 20개 V선의 공간 샘플링 간격이 1.2m 에서 ~4.9cm 라
  σ=5cm 요철이 저샘플링된다. 노이즈 탓이 아니며(σ 0.3~2.4mm 전 구간 동일)
  선 수를 늘리거나 촬영을 겹쳐야 개선된다. eq6 이 편향을 추정해 함께 보고한다.
- **σ_u ≥ 0.5px**: 평활도가 측정불가로 게이트된다. σ_u = 2.0px 에서는 수평도
  오차가 1.35°로 허용을 넘는다.
- **H선은 단독 삼각측량 불가**: 기선이 X축이라 깊이는 u 시차에만 실리고,
  그러려면 발사각 α 를 알아야 하는데 H선은 α 가 점마다 다르다. V선 조밀
  샘플링이 곧 완전한 정보다.
- **SAM/VLM 백엔드 미구현**: 인터페이스만 있다. 활성화하려면 GPU와 모델
  가중치가 필요하다.
- **Isaac 렌더 경로 미검증**: 어노테이터 부착, `pitch_down_deg` 카메라 자세,
  `A_선검출` 실제 연동은 Isaac 환경에서 한 번 실행해 확인해야 한다. 계산
  로직은 전부 `pipeline_region.py`(Isaac 비의존)에 있어 오프라인 검증됨.
